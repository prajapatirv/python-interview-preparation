# Same idea in Java and Python

Programs that teach the same interview topic in both stacks. Run one, then its twin, and compare how each
language solves it. Both example runners read this table and show a **"Same idea in Java / Python"** link
on each program listed here.

**The table is machine-read** (`shared/prepkit/prepkit/pairs.py` for the Python runner,
`JavaPrepLive.java` for the Java runner). Keep one row per topic and the three columns: topic, Java
links, Python links. Links are relative to this folder: Java ones point into
`../java/java-interview-prep/examples/`, Python ones into `../python/python-interview-prep/` (a folder
link means that folder's pytest suite). Separate several links in a cell with ` · `.
`scripts/check_content.py` fails if a link stops resolving.
